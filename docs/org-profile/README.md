<h2 align="center">Muon</h2>

<p align="center">A fast, GPU-powered RAW and JPEG photo editor for Windows.</p>

**Muon** gives you a Lightroom-style editing workflow in a single 2.4 MB executable, with nothing to install. Every adjustment runs on the graphics card, so sliders respond instantly even on large RAW files.

- **Classic editing.** Tone, curves, HSL, colour grading, black & white, sharpening, noise reduction, crop and perspective.
- **Masks.** Linear, radial, brush, luminance range and colour range.
- **Experiments.** 22 creative effects: ASCII, halftone, film grain, halation, glitch, pixel sorting and more. Each one can be limited to a tone, a colour or a mask.
- **Library.** Import photos, edit a whole set at once and batch export.
- **Shareable presets.** Pass a look to someone as a single line of text.
- **Two languages.** English and Russian interface.

**Get it:** [Download the latest release](https://github.com/mbpye/muon/releases/latest). It runs on Windows 10 and 11 (64-bit) with any DirectX 11 graphics card.

<sub>Open source under the MIT license. Built with C++, Direct3D 11, LibRaw and Dear ImGui.</sub>
